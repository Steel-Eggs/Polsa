# 🤖 Польза — Персональный ИИ-ассистент

Этот репозиторий — моё «тело» и «память». Здесь лежат все мои файлы, навыки, дашборды и документы проекта СПУТНИК. 

Ниже приведена **максимально подробная инструкция для новичков** по развёртыванию меня на абсолютно пустом сервере (на примере Ubuntu/Debian). Вы просто копируете команды по очереди и вставляете в терминал.

---

## 🚀 Инструкция по установке (Шаг за шагом)

### Шаг 1. Установка Node.js (Движок)
Платформа работает на JavaScript, поэтому нам нужен Node.js (рекомендуется версия 22). Вставьте эту команду целиком, она скачает и установит нужную версию:
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### Шаг 2. Установка платформы OpenClaw
Теперь ставим саму платформу (моё «ядро»):
```bash
sudo npm install -g openclaw
```

### Шаг 3. Скачивание моей памяти (Git Clone)
Платформа всегда ищет файлы ассистента в специальной папке `~/.openclaw/workspace`. Нам нужно создать эту папку и скачать туда этот репозиторий.
```bash
# Создаем скрытую папку для системы
mkdir -p ~/.openclaw

# Скачиваем репозиторий в папку workspace
# (Если репозиторий приватный, при клонировании по HTTPS потребуется ввести логин и токен доступа от GitHub)
git clone https://github.com/Steel-Eggs/Polsa.git ~/.openclaw/workspace
```

### Шаг 4. Установка зависимостей для скриптов
У меня есть дополнительные программы (например, финансовый дашборд). Им нужны свои пакеты для работы. Выполните:
```bash
cd ~/.openclaw/workspace
npm install
```

### Шаг 5. Настройка секретных ключей (API)
Чтобы я могла писать в Telegram, думать (Google Gemini) и говорить (ElevenLabs), мне нужны доступы.

**1. Ключи для голоса (ElevenLabs):**
Создаем системный файл `.env`:
```bash
nano ~/.openclaw/.env
```
В открывшемся окне вставьте эти три строчки, подставив свой API-ключ от ElevenLabs:
```text
ELEVENLABS_API_KEY=ваш_ключ_от_elevenlabs
ELEVENLABS_VOICE_ID=SAz9YHcvj6GT2YYXdXww
ELEVENLABS_MODEL_ID=eleven_multilingual_v2
```
Сохраните файл: нажмите `Ctrl+O` -> `Enter` -> `Ctrl+X`.

**2. Ключи для Telegram и Gemini:**
Запустите встроенный мастер настройки OpenClaw:
```bash
openclaw configure
```
Мастер задаст пару вопросов прямо в терминале: он попросит вставить токен от Telegram-бота и API-ключ от Google Gemini. Просто следуйте его подсказкам на экране.

### Шаг 6. Запуск службы (Чтобы я работала всегда)
Чтобы я не выключалась, когда вы закрываете терминал, меня нужно установить как фоновую службу:
```bash
openclaw gateway install
systemctl --user start openclaw-gateway.service
```
*(Если вы настраиваете систему под пользователем `root` и systemd ругается, можно запустить шлюз напрямую простой командой: `openclaw gateway start`)*.

### Шаг 7. Пробуждение
Как только служба запустится, откройте наш чат в Telegram и напишите мне команду:
`/clear`

Я сброшу старый кэш, перечитаю все файлы из папки `workspace`, которые мы только что скачали с GitHub, и буду полностью готова к работе на новом сервере! 🎉
